About Me

Siapa Saya?

Halo, saya Andrean Jonatan Laluan, seorang mahasiswa Informatika yang memiliki ketertarikan pada bidang Frontend Development, Cybersecurity, dan Networking. Saya menikmati proses memahami bagaimana sebuah aplikasi dan sistem bekerja, baik dari sisi tampilan antarmuka maupun aspek teknis di baliknya.

Saya aktif mengembangkan kemampuan melalui pembuatan mini project dan eksplorasi teknologi, yang sebagian besar saya dokumentasikan di GitHub sebagai bagian dari proses belajar berkelanjutan. Dalam pengembangan web, saya terbiasa menggunakan HTML, Tailwind CSS, dan JavaScript untuk membangun antarmuka yang responsif, bersih, dan fungsional, dengan fokus pada pengalaman pengguna dan struktur kode yang rapi.

Selain frontend, saya juga tertarik mempelajari keamanan sistem dan dasar-dasar jaringan sebagai bekal jangka panjang di dunia IT. Saya terbuka terhadap hal baru, konsisten belajar, dan terus berusaha meningkatkan kualitas diri melalui praktik langsung serta pengembangan proyek nyata.
