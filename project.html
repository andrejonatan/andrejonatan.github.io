Edukids

- Web Edukasi Anak -


Edukids adalah sebuah platform web edukasi anak yang dirancang untuk memberikan pengalaman belajar yang seru, menyenangkan, dan interaktif secara digital. Website ini fokus pada penyajian konten edukatif dengan antarmuka yang ceria dan ramah anak, serta dilengkapi fitur reservasi untuk memudahkan orang tua dalam mendaftarkan anak-anak mereka ke program pembelajaran yang tersedia. Selain itu, platform ini mengintegrasikan berbagai elemen visual menarik yang bertujuan untuk menstimulasi kreativitas dan rasa ingin tahu anak selama bereksplorasi di dalam situs. Pengembangan Edukids juga mengedepankan kemudahan navigasi agar seluruh fitur dapat diakses dengan cepat, memberikan rasa aman dan nyaman bagi keluarga yang ingin mengoptimalkan potensi belajar anak di era modern.

Berikut adalah tools yang digunakan dalam pengembangan Edukids:

  1. HTML5: Struktur dasar halaman web.
  2. Tailwind CSS: Framework CSS untuk desain responsif dan modern.
  3. Vanilla JavaScript: Untuk interaktivitas ringan di sisi klien.
  4. Font Awesome: Koleksi ikon untuk elemen visual.
  5. AdminLTE Template: Template admin panel berbasis Bootstrap untuk manajemen konten.
  6. GitHub Pages: Layanan hosting statis untuk deployment web dengan custom domain.

Tiketify

- Web Penjualan Tiket Bioskop -


Tiketify adalah aplikasi reservasi tiket bioskop berbasis web yang dibangun menggunakan Django Framework untuk menyediakan solusi pemesanan tiket yang dinamis, aman, dan terstruktur. Web ini dirancang untuk mempermudah pengguna mengeksplorasi daftar film serta melakukan reservasi secara digital, sementara di sisi pengelola, sistem ini menawarkan kemudahan manajemen data film dan jadwal tayang secara efisien. Melalui sistem otomatisasi ini, risiko kesalahan input data dan antrean fisik dapat dikurangi secara signifikan guna meningkatkan kepuasan pelanggan saat bertransaksi. Selain itu, integrasi database yang solid memungkinkan platform ini menyimpan riwayat pemesanan secara akurat, sekaligus memberikan skalabilitas bagi pengembang untuk menambahkan fitur-fitur baru di masa mendatang.

Berikut adalah tools yang digunakan dalam pengembangan Tiketify:

  1. Django (Python): Framework utama untuk backend dan logika sistem.
  2. Bootstrap: Framework untuk desain UI yang responsif.
  3. AOS (Animate On Scroll): Library untuk efek animasi scroll.
  4. Font Awesome: Koleksi ikon untuk elemen visual.
  5. HTML5 & CSS3: Struktur dasar dan styling halaman web.
  6. Vanilla JavaScript: Untuk interaksi ringan di sisi klien.
